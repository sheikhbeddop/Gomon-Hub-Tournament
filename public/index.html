  1. আপনার বিকাশ/নগদ সিমটি যে অ্যান্ড্রয়েড ফোনে আছে, সেটিতে গুগল প্লে-স্টোর থেকে MacroDroid - Device Automation ফ্রি অ্যাপটি ইনস্টল করুন।

  3. এরপর Actions (+) চাপুন > Connectivity > HTTP Request সিলেক্ট করুন:
    • HTTP Method: POST
    • URL: উপরের Webhook URL টি পেস্ট করুন।
    • Content Type: application/json
    • Content Body: {"sms_content": "{sms_message}", "sender": "{sms_number}", "secret": "gomon_auto_secret_2026"}
